# Roadmap

## 0.1.x: public commercial preview

- Flexible recognition of common YouTube Studio export headers
- Markdown, HTML, CSV and JSON output
- Channel-relative discovery and retention signals
- Rights holds and low-sample RPM audits
- Synthetic demonstration and reproducible tests

## 0.2: comparison engine

- Compare two or more date windows
- Preserve experiment cohorts
- Track title and thumbnail test dates
- Separate organic and promoted traffic where supplied
- Show gains, losses and confidence warnings

## 0.3: multi-channel agency workflow

- Batch analysis
- Portfolio summaries
- Client-safe export packs
- Commercial licence validation
- Configurable branding

## 1.0: stable operating contract

- Versioned input schema
- Versioned scorecard schema
- Migration documentation
- Expanded accessibility review
- Independently reproduced fixture suite

Roadmap items are intentions, not promises. Scope follows evidence, buyer demand and maintainability.
