# Contributing

Contributions that improve import compatibility, analytical transparency, accessibility, tests or documentation are welcome.

1. Do not submit real creator analytics.
2. Use synthetic fixtures.
3. Add or update tests for behavioural changes.
4. Do not add telemetry, credential collection, view inflation, engagement manipulation or spam automation.
5. Explain the operating hypothesis behind a new score or classification.
6. Keep projections visibly separate from observed data.

By contributing, you license your contribution under the repository's public licence and permit the copyright holder to offer the combined work under separate commercial terms. Submit only work you have the right to contribute.
