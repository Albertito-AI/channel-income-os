# Channel Income OS v0.1.0

The first public commercial preview of Channel Income OS is an API-free, local-first tool that converts YouTube Studio CSV exports into an evidence-led creator income operating report.

## Included

- flexible CSV ingestion for common YouTube Studio export headings;
- explicit income-target and RPM scenario mathematics;
- discovery, packaging, retention, scaling, rights-hold and revenue-audit signals;
- Markdown report, HTML dashboard, CSV action queue and JSON scorecard;
- synthetic demonstration data and reproducible demo outputs;
- rights, experiment and revenue ledgers;
- seven automated behavioural and CLI tests;
- no telemetry and no Google or YouTube API requirement.

## Install

Download the wheel attached to this release, then run:

```bash
python -m pip install channel_income_os-0.1.0-py3-none-any.whl
channel-income-os demo
```
